# Script de Démonstration - PLANORA 360

> **« Planifiez. Suivez. Évaluez. Agissez. Performez. »**

*Plateforme intégrée de planification, suivi-évaluation, gestion financière et pilotage de la performance.*

---

## 🎯 Introduction (2 minutes)

**PLANORA 360** transforme la gestion de vos projets en un système intégré de pilotage de la performance.

### Problématique
- Difficulté à suivre l'exécution des activités
- Manque de visibilité sur l'avancement des projets
- Capitalisation des connaissances non structurée
- Validation hiérarchique complexe

### Solution
Une plateforme centralisée qui permet de :
- ✅ Planifier et structurer les activités
- 📊 Suivre en temps réel l'avancement
- 💰 Gérer les budgets et participants
- ✔️ Valider les activités (circuit hiérarchique)
- 📚 Capitaliser les bonnes pratiques

---

## 📋 Modules Principaux

### 1. Plans d'Action
- Créer des plans avec période définie
- Organiser par axes stratégiques
- Ajouter des activités hiérarchisées

### 2. Activités
- Définir responsables et collaborateurs
- Fixer délais et priorités
- Suivre l'avancement avec checklist
- Gérer les budgets prévisionnels/exécutés

### 3. Validation
- Circuit de validation à 5 étapes
- Workflow hiérarchique
- Décisions : Approuvé / Rejeté / En attente

### 4. Participants
- Gestion des bénéficiaires
- Import Excel massif
- Suivi paiements (Wave, Orange Money)

### 5. Capitalisation
- Bonnes pratiques
- Récits de changement
- Guides méthodologiques
- Avec médias (photos, vidéos)

### 6. Planification
- Plan de travail annuel
- Matrice de résultats
- Vision stratégique

## 🎬 Déroulé de la Démo (15 minutes)

### Phase 1 : Connexion (1 min)
1. Ouvrir http://localhost:3001
2. Se connecter avec compte démo
3. Montrer le dashboard d'accueil

### Phase 2 : Tableau de Bord (2 min)
```
Vue d'ensemble :
- Nombre d'activités en cours
- Taux d'avancement global
- Budget consommé vs prévisionnel
- Activités en retard
```

**Point clé** : Vision centralisée en temps réel

---

### Phase 3 : Plan d'Action (3 min)

#### Créer un nouveau plan
```
Navigation : Plans d'action → Nouveau plan

Exemple :
- Titre : "Plan 2026 - Développement Communautaire"
- Période : 01/01/2026 - 31/12/2026
- Objectifs stratégiques : Renforcer les capacités locales
```

#### Ajouter un axe
```
Exemple : "Axe 1 - Formation et Renforcement"
```

#### Créer une activité
```
Titre : Formation des leaders communautaires
Responsable : Sélectionner un utilisateur
Dates : 15/03/2026 - 30/04/2026
Priorité : HAUTE
Budget prévisionnel : 2 500 000 FCFA
```

**Point clé** : Organisation hiérarchique claire

---

### Phase 4 : Suivi d'Activité (3 min)

#### Accéder à une activité
```
Navigation : Activités → Cliquer sur une activité
```

#### Montrer les onglets
1. **Détails**
   - Informations générales
   - Responsable et collaborateurs
   - Dates et priorité

2. **Checklist**
   - Créer une tâche : "Réserver la salle"
   - Assigner un responsable
   - Cocher au fur et à mesure
   - **Le taux d'avancement se calcule automatiquement**

3. **Budget**
   - Budget prévisionnel vs exécuté
   - Ajouter des dépenses
   - Voir le reste à utiliser

4. **Documents**
   - Uploader PV de réunion
   - Photos de l'activité
   - Rapports

**Point clé** : Tout est centralisé, rien ne se perd

---

### Phase 5 : Circuit de Validation (2 min)

#### Soumettre une activité
```
Activité complétée → Bouton "Soumettre pour validation"
```

#### Les 5 étapes
```
1. SOUMISSION → Activité terminée
2. VERIFICATION_HIERARCHIQUE → N+1 vérifie
3. VALIDATION_TECHNIQUE → Expert valide la qualité
4. VALIDATION_ADMINISTRATIVE → Admin valide les aspects financiers
5. CLOTURE → Activité archivée
```

#### Montrer la liste "En attente de validation"
```
Navigation : Validations → Activités en attente
```

**Point clé** : Traçabilité complète des décisions

---

### Phase 6 : Gestion des Participants (2 min)

#### Import Excel
```
Navigation : Participants → Importer

Fichier Excel avec colonnes :
- Prénom
- Nom  
- Téléphone
- Mode de paiement (Wave / Orange Money)
- Montant
```

#### Ajout manuel
```
Participants → Nouveau participant

Exemple :
- Prénom : Fatou
- Nom : Diop
- Téléphone : 77 123 45 67
- Paiement : Wave
- Montant : 50 000 FCFA
- Activité : Formation des leaders
```

**Point clé** : Suivi précis des bénéficiaires et paiements

---

### Phase 7 : Capitalisation (2 min)

#### Créer une bonne pratique
```
Navigation : Capitalisation → Nouvelle capitalisation

Type : Bonne pratique

Exemple :
- Titre : "Mobilisation communautaire par les radios locales"
- Contexte : Village éloigné, difficile à mobiliser
- Défis : Analphabétisme, pas d'accès internet
- Solutions : Partenariat avec radio locale pour sensibilisation
- Résultats : 85% de participation vs 30% avant
- Leçons : Utiliser les canaux traditionnels avant le digital

Tags : mobilisation, communication, radio

+ Ajouter des photos/vidéos
```

**Point clé** : La mémoire institutionnelle structurée

---

### Phase 8 : Planification Stratégique (1 min)

```
Navigation : Planification

Plan de Travail Annuel :
- Vision globale de l'année
- Activités prévues par trimestre
- Budget consolidé

Matrice de Résultats :
- Objectifs
- Indicateurs
- Résultats attendus
```

**Point clé** : Vision stratégique à long terme

## 💡 Points Forts à Souligner

### 1. Multi-tenant
- Chaque organisation est isolée
- Données sécurisées
- Personnalisation (logo, couleur de marque)

### 2. Gestion des rôles
```
- ADMIN : Tous les droits
- MANAGER : Gestion d'équipe
- USER : Exécution d'activités
- VIEWER : Lecture seule
```

### 3. Tableaux de bord temps réel
- Pas besoin d'attendre les rapports mensuels
- Vision immédiate de la situation

### 4. Audit complet
- Qui a fait quoi, quand
- Traçabilité de toutes les actions

### 5. Mobile-first
- Interface responsive
- Utilisable sur smartphone/tablette

## ❓ FAQ Anticipées

### "Peut-on exporter les données ?"
Oui, export Excel/PDF des rapports, activités, participants.

### "Comment gérer plusieurs projets ?"
Chaque plan d'action est indépendant, vous pouvez en créer autant que nécessaire.

### "Peut-on recevoir des notifications ?"
Oui, notifications par email (configurable) pour :
- Activités en retard
- Validations en attente
- Fin de période

### "Stockage des documents ?"
Backblaze B2 (sécurisé, redondant), pas de limite de taille pour l'organisation.

### "Langue ?"
Interface en français, peut être étendue à d'autres langues.
